# §A 论文核心规格（自包含，照此实现，不要凭记忆改写）

## A1 问题定义与记号
多变量长期预测：给定回看 X = {x_1,…,x_T} ∈ R^{T×N}（T 步、N 个变量），预测 Y = {x_{T+1},…,x_{T+S}} ∈ R^{S×N}。
约定：X_{t,:} 为同一时刻所有变量的观测（物理含义不同、可能有系统性时滞）；X_{:,n} 为第 n 条变量的完整序列。
模型学 f: R^{T×N} → R^{S×N}；指标 MSE、MAE，在标准化空间计算，越小越好。
本文只做多变量点预测（非概率预测），不涉及缺失值填补与分类。

## A2 模型结构与公式（论文式 1、2 与 3.2 节）
逐变量嵌入（Embedding 由 MLP 实现，T→D）：
    h⁰_n = Embedding(X_{:,n}),            n = 1,…,N
堆叠 L 个倒置 block（每层共享同一 FFN 与注意力权重）：
    H^{l+1} = TrmBlock(H^l),              l = 0,…,L−1,   H ∈ R^{N×D}
逐变量投影（Projection 由 MLP 实现，D→S）：
    Ŷ_{:,n} = Projection(h^L_n)
block 内部顺序：变量维 LayerNorm → 变量维多头自注意力 → 残差 → 变量维 LayerNorm → FFN（逐 token，D 维）→ 残差。
LayerNorm 作用在每条变量的表征上（论文式 2）：
    LayerNorm(H) = { (h_n − Mean(h_n)) / sqrt(Var(h_n)) },  n = 1,…,N
注意力打分（token 数为 N，不是 T）：
    Q,K,V ∈ R^{N×d_k};  A_{i,j} = (QKᵀ/√d_k)_{i,j} ∝ q_iᵀ k_j
不使用位置编码（序列顺序隐含在 FFN 的神经元排列中）。输出 Ŷ 由 N×S 转置回 S×N。
复杂度与显存：注意力 O(N²·d_k)，嵌入 O(N·T·D)，投影 O(N·D·S)；显存随 N² 增长，Traffic(862)/ECL(321) 由 N 决定。

## A3 三个组件在倒置维上的语义（写进代码注释与报告方法章）
- LayerNorm（变量维）：把每条变量的整段序列标准化到近似高斯，消除量纲与分布差异，缓解非平稳；在旧结构里它标准化同一时刻的多变量向量，会把不相关的过程强行耦合。
- FFN（时间维）：对每个 variate token 独立、共享地做 D 维非线性变换；神经元扮演"滤波器"角色，学习幅值、周期、频谱等序列表征。它等价于"通道独立的共享线性预测头 + 非线性"，这是能吃更长回看窗口的原因。
- Attention（变量维）：N 个变量 token 之间的注意力，权重矩阵 A∈R^{N×N} 直接给出变量相关性；论文展示浅层 A 与回看序列的 Pearson 相关图接近，深层 A 与未来序列的相关图接近，因此具备可解释性。
- 分工结论：**不要**按 vanilla Transformer 的方式在时间步上做注意力；把注意力放回时间维就是本文要否定的设计（消融里对应"时间维 Attention"，在 Traffic 上 MSE 从 0.428 退化到 0.863～0.913）。

## A4 实现要点与保真要求
官方 model/iTransformer.py 的结构与 A2 完全一致，改造前先按行号确认四点：① 输入 transpose 后在 N 维做 attention；② FFN 作用于最后一个维度；③ 没有位置编码；④ 输出层是 Linear(D, S) 后 permute。
语义等价的最小骨架（仅用于理解与写测试，正式实验仍用官方实现）：
```python
class Model(nn.Module):
    def __init__(self, seq_len, pred_len, d_model=512, d_ff=512,
                 e_layers=2, n_heads=8, dropout=0.1):
        super().__init__()
        self.enc_embedding = nn.Linear(seq_len, d_model)        # 逐变量共享: T -> D
        self.encoder = nn.ModuleList([
            nn.TransformerEncoderLayer(d_model, n_heads, d_ff, dropout,
                                       batch_first=True, norm_first=False)
            for _ in range(e_layers)])                          # 注意力在序列维(此处=N)
        self.norm = nn.LayerNorm(d_model)
        self.projector = nn.Linear(d_model, pred_len)           # D -> S

    def forward(self, x):                 # x: B, T, N
        x = x.permute(0, 2, 1)            # B, N, T
        h = self.enc_embedding(x)         # B, N, D
        for blk in self.encoder:
            h = blk(h)                    # 变量维注意力 + 逐 token FFN
        return self.projector(self.norm(h)).permute(0, 2, 1)    # B, S, N
```
保真要求（写进 tests/）：
1) 默认配置下，你的封装与官方入口在同一 commit、同一种子下输出的 metrics 应一致（差异 <1e-3）；若因加 --seed 改了种子序列，先固定种子再比。
2) 断言输出形状 (B, S, N)，断言 enc_in/dec_in/c_out == 数据变量数。
3) 断言注意力权重矩阵形状 (B, heads, N, N)，可保存一层用于可解释性图。
4) 六种消融组合都能前向且形状不变（对应论文 Table 6 的完整模型 / Replace Attention→Attention / Replace FFN→Attention / Replace FFN→FFN / w/o Attention / w/o FFN）。

随机性说明（本项目只有一类）：
- 训练随机性（初始化、批采样、非确定算子）→ 用 3 个种子度量；论文无早停，因此不存在早停随机性

- 若某配置只跑 1 个种子，视为不合格

## B6 合规执行顺序（8 步，顺序不能反）
1. 固定划分：先跑 check_data.py，确认 train/val/test 索引与 A8 一致，样本数打印存档
2. 固定指标：用一个小样例手算 MSE/MAE，与 utils/metrics.py 对齐；确认在标准化空间
3. 先跑基线（DLinear），确认量级合理，再跑 PatchTST
4. 再跑主方法单次，确认优于基线且量级接近 A6
5. 补齐 3 个种子，报均值±std，保留全部单次结果
6. 做一项深入分析（消融或回看），固定其余条件
7. 与论文逐档对照，形成差异表，给出"支持/部分支持/不支持/证据不足"的判定
8. 由脚本汇总出表与图，写报告，做干净环境复跑
常见风险（逐条自检）：测试集调参 / 基线 batch 与主方法不同 / 只报最好一次 / 指标取错下标（metrics.npy 首位是 MAE）/ 变量数填错 / ETT 切分口径混用。
